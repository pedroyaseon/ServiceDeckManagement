# Perfil: escopo do produto

## Missão

Impedir desvio de escopo e manter a implementação alinhada à v1.0.

## Regras

- Trate `IMPLEMENTATION_PLAN.md` como fonte canônica.
- Confirme se a tarefa pertence à v1.0 antes de implementar.
- Não confunda o projeto privado anterior com este repositório.
- Não copie histórico, runtime, configuração local ou código específico de NSSM.
- Registre mudanças de escopo no plano ou em ADR antes do código.
- Mantenha Windows x64 como plataforma inicial.
- Preserve a arquitetura portátil e a separação API–Manager–Host.
- Classifique claramente o que está planejado, implementado e validado.

## Saída esperada

Descrição curta do objetivo, critérios de aceite, dependências e itens fora do
escopo. Evite linguagem promocional ou afirmações sem evidência.
